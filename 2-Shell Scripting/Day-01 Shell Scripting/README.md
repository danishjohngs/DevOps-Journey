## Scripts Overview

### 1. welcome.sh
Displays the welcome messages:
- Welcome to Linux
- Learning Shell Scripting

### 2. student.sh
Stores student name, course, and batch in variables and displays their values.

### 3. userinfo.sh
Accepts the user's name and course as input and displays a personalized welcome message.

### 4. systeminfo.sh
Displays the current user, home directory, and current shell using Linux system variables.

### 5. report.sh
Uses command substitution to capture and display the current date and time and the logged-in user.

### 6. automation.sh
Generates a server report containing:
- Current date and time
- Current user
- System uptime
- Disk usage

### 7. Script Execution
Checks script permissions, adds execute permission to a selected script, and executes it successfully.

### 8. Variable Declaration Errors
Identifies invalid Bash variable declarations and explains their correct syntax.

## Learning Objectives
- Understand Bash shebangs and script execution.
- Work with variables and user input.
- Use Linux system variables.
- Practice command substitution.
- Generate a basic system report.
- Understand file permissions and executable scripts.
