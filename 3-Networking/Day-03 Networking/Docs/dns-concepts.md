## Domain name
**Domain name is human readable name that given to a IP address of a website that helps to users to memorize.**

## DNS
**Domain Name System is used to convert Domain names to IP address. Computers only knows IP addresses and human only knows the domain names, so DNS acts as a bridge between client and the server that helps to convert the domain name to IP address.**

## A record
**An A Record is a DNS record that maps a domain name or hostname to an IPv4 address. It tells DNS which IPv4 address is associated with a domain.**

## CNAME
**A CNAME Record maps one domain name to another domain name (an alias). It is commonly used to connect a www subdomain to a hosting provider's domain.**

## HTTP
**HTTP HyperText Trasfer Protocol, It is a communication protocol used by web browsers and web servers to exchange information.**

*Client <-----------------> Server*

## HTTPS
**HTTPS HyperText Transfer Protocol Secure, It is the secure version of HTTP. HTTPS uses TLS encryption to protect communication between a browser and a web server.**

## SSL/TLS
**SSL and TLS are cryptographic protocols used to secure communication over networks.**
- SSL is an older protocol and is no longer considered secure.
- TLS is its modern successor and is used by HTTPS today.
TLS helps protect communication through encryption, authentication, and integrity checks.

## DNS Resolution
**DNS Resolution is the process of finding the DNS records associated with a domain name so that a browser can locate the requested internet service.**

## Public IP address
**A Public IP Address is an IP address that is globally routable on the internet. It is used to identify an internet-connected destination or network interface so that devices and services can communicate over the public internet.**

## Private IP address
**A Private IP Address is an IP address used inside a private network, such as a home, college, or office network. Private IP addresses are not directly routable across the public internet. Devices commonly use a router with Network Address Translation (NAT) to access the internet.**
