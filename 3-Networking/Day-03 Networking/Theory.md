# PART A – THEORY QUESTIONS

### 1. What is an IP Address?
An IP (Internet Protocol) Address is a unique logical address used to identify a device on a network.

### 2. Why does every device require an IP Address?
To identify devices and enable communication between them over a network.

### 3. What is IPv4?
IPv4 (Internet Protocol Version 4) is a protocol that uses 32-bit addresses to identify devices on networks.

### 4. How many bits are present in an IPv4 address?
An IPv4 address contains **32 bits**.

### 5. What are Octets in an IPv4 address?
An octet is a group of 8 bits in an IPv4 address. It contains four octets.

### 6. What is the valid range of each IPv4 octet?
Each octet ranges from **0 to 255**.

### 7. Differentiate between Public IP and Private IP.
- **Public IP:** Used for communication over the internet.
- **Private IP:** Used for communication within private networks.

### 8. Give three examples of Private IP ranges.
- `10.0.0.0 – 10.255.255.255`
- `172.16.0.0 – 172.31.255.255`
- `192.168.0.0 – 192.168.255.255`

### 9. Who assigns a Public IP Address?
An Internet Service Provider (ISP) assigns public IP addresses to customers.

### 10. What is DHCP and why is it used?
DHCP (Dynamic Host Configuration Protocol) automatically assigns IP configuration to devices on a network.

### 11. What information does DHCP automatically provide to devices?
- IP Address
- Subnet Mask
- Default Gateway
- DNS Server Address

### 12. What is a Default Gateway?
A default gateway is the device, usually a router, that forwards traffic from a local network to other networks.

### 13. What role does a Router play in a network?
A router connects different networks and forwards data packets between them.

### 14. Explain how a device accesses a website using ISP services.
1. The device connects to a network through a router.
2. DNS resolves the website's domain name into an IP address.
3. The router forwards traffic through the ISP.
4. The ISP routes the traffic to the destination server.
5. The server sends a response back to the device.

### 15. Why is IP Addressing important in DevOps and Cloud environments?
IP addressing enables communication between servers, containers, applications, and cloud resources. It is essential for networking, routing, security, and troubleshooting.
