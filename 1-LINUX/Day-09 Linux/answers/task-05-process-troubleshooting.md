**What is a PID?**

A Process ID is the numeric identifier assigned to a running process.



**What is the difference between kill and kill -9?**

kill sends SIGTERM by default, allowing graceful termination. kill -9 sends SIGKILL, which forces termination without allowing the process to handle the signal. Use it only when normal termination fails and it is appropriate.



**What is htop used for?**


 It provides an interactive view of running processes and resource usage, including CPU and memory. It may need to be installed separately.
