# SSH and Cron Service Health Check

## Objective

To perform a health check of the SSH and Cron services by inspecting their current status, enabled state, and recent logs.


## 1. SSH Service Health Check

### Current Status

Command used:

```bash
systemctl status ssh
```

Terminal output:

```text
○ ssh.service - OpenBSD Secure Shell server
     Loaded: loaded (/usr/lib/systemd/system/ssh.service; disabled; preset: enabled)
     Active: inactive (dead)
  TriggeredBy: ○ ssh.socket
       Docs: man:sshd(8)
             man:sshd_config(5)
```

Enabled-state command:

```bash
systemctl is-enabled ssh
```

