# Linux Service Report

## Objective

To inspect Linux services and report their current status, enabled/disabled state, and recent log information.

## Service Report

| Service Name | Current Status | Enabled/Disabled State | Recent Log Information |
|---|---|---|---|
| `docker` | Active (running) | Enabled | Docker daemon completed initialization and started successfully. Startup logs also show nftables IPv4/IPv6 rule-deletion messages containing errors; the service nevertheless reached `active (running)`. |
| `nginx` | Active (running) | Enabled | Logs show Nginx stopping and starting successfully. The latest provided entries end with `Started nginx.service`. |
| `cron` | Active (running) | Enabled | Logs show cron starting, running `@reboot` jobs, and executing the hourly cron job. A startup message notes that `EXTRA_OPTS` is unset and evaluates to an empty string. |



## Commands Used

```bash
systemctl status docker
systemctl is-enabled docker
journalctl -n 10 -u docker

systemctl status nginx
systemctl is-enabled nginx
journalctl -n 10 -u nginx

systemctl status cron
systemctl is-enabled cron
journalctl -u cron -n 10
```
