## PART B – THEORY QUESTIONS (15 Questions)

### 1. Define Linux.
```
Linux is a core software programe called kernal, hat controls hardware, memory, processer. It is a engine that runs inside the Operating system (Ubuntu).
```
### 2. What are the advantages of Linux?
* Faster
- Highly Secure
- Open Source
- stable
- easy customization

### 3. Why is Linux widely used in DevOps?
```
Linux is popular in DevOps because it is reliable, secure, and makes it easy to manage servers and automate tasks.
```
### 4. Explain the difference between Linux and Ubuntu.
```
Linux is the core (kernel), while Ubuntu is a complete operating system based on Linux.
```
### 5. What is a Linux Distribution?
```
A Linux distribution is a complete operating system built using the Linux kernel, along with other software and tools.
```
### 6. What is Ubuntu?
```
Ubuntu is a popular Linux distribution based on Debian. It is commonly used for desktops, servers, cloud systems, and development.
```
### 7. What is WSL?
```
WSL (Windows Subsystem for Linux) is a Windows feature that allows users to run a Linux environment directly inside Windows without using a traditional virtual machine.
```
### 8. Explain the relationship between Windows, WSL, and Ubuntu.
```
Windows is the main operating system. WSL is a Windows feature that provides a Linux environment. Ubuntu is one of the Linux distributions that can run inside WSL.
```
### 9. Why do Windows users install Ubuntu through WSL?
```
To use Linux commands, tools, and development environments while still using Windows as their main operating system.
```
### 10. Explain how WSL helps developers.
```
WSL allows developers to use Linux tools and commands directly on Windows. It is useful for programming, scripting, Git, DevOps, cloud, and server-related work.
```
### 11. Explain the purpose of the pwd command.
```
pwd shows the current working directory.

### 12. Explain the purpose of the ls command.

ls lists the files and directories in the current directory.

whoami shows the username of the user currently logged in.

### 14. Explain the purpose of the hostname command.

hostname displays the name of the computer or system you are currently using.
